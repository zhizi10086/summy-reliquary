## 模组概述

Summy Reliquary 是一个以 **Curios** 为前置的七罪主题饰品与武器模组（Minecraft 1.20.1 / Forge），灵感来自《以撒的结合》，围绕七宗罪与天使 / 恶魔两条线展开。

- **起点**：首次进入世界会拿到「七罪之源」与「光环」；七宗罪各有自己的触发条件，觉醒后同时带来增益与减益，把某一项**赎罪**可以只保留增益。
- **天使线**：把七罪**全部赎罪**、再用「赎罪」把七罪之源转化为「美德」，就走上天使线 —— 灵台三件套 → 伯列恒之星 → 终末天启 → 神性，武器是两把长矛（圣光短矛 / 炽天使之枪）。
- **恶魔线**：在**灵魂沙峡谷**被邀请并与恶魔签约则走上恶魔线 —— 契约 → 仪式法袍 → 撒旦圣经 → 咒印 → 夜之幽魂 → 硫磺火 → 深渊领主 → 亚巴顿，武器是两把匕首（献祭匕首 / 暗仪刺刀），另有「邪恶度」档位与恶魔王冠。两条线互斥：**666 之后永久锁死天使线**。
- **隐藏挑战**：不佩戴七罪之源击杀末影龙 = 「无罪之人」（之后永久无法再佩戴）；佩戴且七罪全未激活击杀 = 「纯洁无瑕」（七罪直接全部赎罪）。
- **重置**：两条线各会自动发放一个「创世纪」，右键确认后**除成就外一切从头开始**（唯一例外：无罪之人的锁保持）；此外还有无派系的中立武器「金刀片」。

## 首次进入世界的发放与右键规则

- 玩家**首次进入世界**（按玩家存档里的标记判定，老玩家下次登录会补发一次、不会重复）会自动获得
  **七罪之源**与**光环（the halo）**，两件都只放进背包、**不自动佩戴**；背包满则掉在脚下。
- 七罪之源是否**开局自动装进魂印栏**由配置 `start.auto_equip_source_of_sins` 决定（默认 `false`）；
  整个发放可以关掉（`start.grant_items = false`）。
- **右键快捷佩戴**：七罪之源**禁止**（必须手动放进魂印栏）；**光环允许**右键直接佩戴。
  其它饰品保持 Curios 的默认行为（默认不允许右键，需手动放入栏位）。

## 飞行（终末天启）

佩戴终末天启时：**创造 / 旁观模式**保持原版飞行速度 `0.05`，半速只作用于「授予生存玩家的飞行」——
生存/冒险玩家会获得飞行能力并把速度设为 `0.05 × flight_speed_multiplier`（默认 `0.025`，即一半）；
卸下后收回该能力并恢复 `0.05`。

## 蓄力特效（启示之光）

长按 `V` 蓄力时：屏幕按**拉弓方式收缩 FOV**（默认最多 −15%，配置 `revelation.charge_fov_scale`），
并在玩家**身体侧下方**持续生成**白色 `END_ROD` 粒子**（由服务端生成，自己也看得到、附近玩家同样可见）：
粒子分布在以胸口偏下为圆心、**排除正前方 ±20°** 的环绕弧上，半径随蓄力从 **1.9 格收缩到 0.4 格**，
因此既不挡视线中央、又能形成"周围生成、向中心聚拢"的观感；密度约为每 2 tick 2 颗（一次完整蓄力约 50 颗）。
蓄满瞬间补一次白色闪光。松手/中断/冷却中都会立即清除蓄力状态并恢复 FOV。

- **忏悔与二次签约**：用一次**痛悔短祷**可把恶魔标记换回天使标记（最多签两次）；一旦**获取过启示**，恶魔交易彻底关闭，只能靠**创世纪**重置。
- **命令（仅 OP）**：`/summyreliquary demon <query|grant|revoke> <玩家>`、`/summyreliquary pentagram <query|grant|reset> <玩家>`。

**「近乎完美」推荐路线**

1. 开局戴上七罪之源，走**任意一条线**并拿齐该线成就；
2. 该线走完后**使用创世纪**（清掉七罪状态、天使标记、整条恶魔线与**七罪佩戴计时**；**成就全部保留**）；
3. 重开后走**另一条线**；
4. **两段线之间至少完成一次「纯洁无瑕」**——第一段若走天使线可在其间完成；若第一段走了恶魔线，则在重置后的第二段完成（签约会一直排斥末影龙挑战，直到创世纪清掉"曾签约"）；
5. **全程不要拿「无罪之人」**：拿过它就永久锁死七罪之源，也就永远拿不到「纯洁无瑕」与「近乎完美」。

**天使体系**

- 「纯洁之人」完成后获得**天使标记**（存在本模组 NBT 里，随死亡克隆保留）。
- 灵台三件套 / 伯列恒之星 / 终末天启：没有天使标记时**不能佩戴、也查不到功能描述**（提示只显示名称、栏位行、风味行与一行「你尚未获得天国的赐福」）。
- 拿到标记后，**聊天栏、Tab 列表与头顶名字都会变成金色**——服务端会广播「有天使标记的在线玩家名单」，客户端按 UUID 染色，所以**谁有标记谁才金**。
- 命令：`/summyreliquary angel <query|refresh|grant|revoke>`（标记只在 NBT 里，没有命令无法查看/调试）。**命令做了权限分层**：`query` / `refresh` 任何玩家都能用；`grant` / `revoke` **仅 OP（等级 2）**——否则任何玩家都能自己发标记绕过纯洁之人这条进度门槛。`revoke` 不会强制卸下已佩戴的物品。
- 两条末影龙挑战都与「解放末地」同口径（击杀者是该玩家），且**互斥**：佩戴与否。
- **末影龙采用「一次性裁决」**：第一次击杀末影龙时按当时状态判定一次（无罪之人 **或** 纯洁无瑕），之后不再重判——否则同一次击杀会被判两次，可能**同时解锁两个成就**。
- 老存档自愈：登录与每秒会检查——「纯洁之人」已完成但缺天使标记 → 补发；「无罪之人」已完成但缺「放弃一切」标记 → 补标记；裁决为纯洁无瑕但七罪之源还没被换掉 → 补做转化。
- 管理命令 `/summyreliquary dragon <query|reset>`（**仅 OP**）：查看或清空末影龙裁决与「放弃一切」标记（误发恢复 / 复测用；进度本身用 `/advancement revoke @s only summy-reliquary:sinless` 撤销）。
- 管理命令 `/summyreliquary pentagram <query|grant|reset> <玩家>`（**仅 OP**，1.5.8）：
  `query` 打印「进度是否完成 / 是否已发放 / 身上数量」；`grant` 立刻补发一个五芒星并置位标记；
  `reset` 清掉发放标记（之后每秒兜底会在「罪无可赦」已完成时再补发一次）。
- 管理命令 `/summyreliquary demon <query|grant|revoke> <玩家>`（**仅 OP**，1.5.9）：
  `query` 打印「恶魔标记 / 已签契约 / 已受邀 / 天使标记」；`grant` 直接给恶魔标记并标为已签约（清掉天使标记）；
  `revoke` 只撤销当前恶魔标记（契约历史保留；**忏悔后仍可二次签约**，见「恶魔交易」一节）。

**美德继承**

- 佩戴**美德**时，会继承七罪「赎罪后」保留的全部增益：傲慢 / 嫉妒的增伤、暴怒（随机上限 2.0 且不再自伤）、怠惰（抗性提升 II）、贪婪（钻石增伤）、暴食（击杀回复）、色欲（攻击脱目标护甲）。

- 七德各自的额外加成留待后续版本添加。

**灵台三件套的合成表**

## 七罪激活与「光环」联动

- 状态按玩家存档保存（跨死亡保留、卸下不清除），三态：**未激活（灰）/ 已激活（暗红↔亮红呼吸）/ 已赎罪（纯金色）**。
- **命令分成两档**：

```
# 玩家可用（只作用于自己）
/summyreliquary sin list
/summyreliquary sin <pride|greed|lust|envy|gluttony|wrath|sloth> query
/summyreliquary sin refresh      # 重新把七罪状态同步到客户端并重算属性
/summyreliquary angel query
/summyreliquary angel refresh
/summyreliquary genesis confirm  # 创世纪的聊天按钮「[是]」就是执行这条（也可手打）
/summyreliquary genesis cancel   # 「[否]」：取消这次确认

# 仅 OP（权限等级 2）
/summyreliquary sin <罪> <on|off|redeem|unredeem>     # off / unredeem 可以撤销已赎罪
/summyreliquary sin all <on|off|redeem|unredeem>      # 一次性把七罪设成同一状态（调试用）
/summyreliquary slots            # 打印所有 Curios 栏位内容（诊断用）
/summyreliquary angel grant|revoke
/summyreliquary dragon query|reset
/summyreliquary salvation <玩家> <on|off|query>  # 救恩名单（同一份名单也管神性光环的玩家目标）
/summyreliquary pentagram <query|grant|reset> <玩家>  # 五芒星：查询 / 补发 / 清掉发放标记
/summyreliquary demon <query|grant|revoke> <玩家>     # 恶魔交易：查询 / 直接发放（含已签约）/ 撤销
/summyreliquary genesis reset <玩家>   # 重置一次性标记（创世纪 / 痛悔短祷 / 恶魔交易），并清契约与邪恶度、收回恶魔契约栏位
```

> 之所以把改状态的入口收归 OP：天使标记与末影龙裁决都是进度门槛，任何玩家都能自己发放会直接绕过玩法。

- **碎片赎罪**：**佩戴七罪之源**时，手持对应的七宗罪碎片在世界里右击，可把该罪从「已激活」变为「已赎罪」，碎片不消耗。
- **七罪赎清**（全部已赎罪）后，七罪之源的风味行变成亮蓝的「他等待你最后的救赎」；此时才允许用「赎罪」右击把它变成美德，未赎清时会提示「七罪未清」且不消耗赎罪。
- **赎罪配方**：七种碎片各 1 + 下界之星 ×1 → 赎罪 ×1；只对「七罪均已赎罪」的玩家开放——服务端在取出产物时拦截并退回材料，装了 JEI 时还会按玩家隐藏该配方（未装 JEI 时仅服务端拦截）。
- 七罪之源的 Shift 列表按配对顺序显示：傲慢 / 贪婪 / 色欲 / 嫉妒 / 暴食 / 愤怒 / 懒惰
  （对应 谦逊 / 慷慨 / 贞洁 / 善良 / 节制 / 耐心 / 勤勉）；游戏内文本统一写作**怠惰**。
- 佩戴七罪之源且至少激活一项 → **「光环」整套属性 ×0.5**，并在光环提示里追加「你当知罪」；
  佩戴美德 → **整套属性 ×2**，追加行换成「你已赎罪」（两者同占魂印栏，互斥）。
- 注意：**已赎罪**的罪不再触发光环减半，只有「已激活且未赎罪」才会。
- 所有饰品**不可重复佩戴**：同一种饰品不能在 Curios 里同时装两份（灵台 3 格因此无法堆同一件）。

## 七罪的具体效果

七罪之源戴上后，每一项罪都有一条**触发条件**：满足条件即自动「觉醒（已激活）」并弹出一条**红色**提示
（色欲的隐藏条件除外）；赎罪成功的提示为**金色**。所有计数**只在佩戴七罪之源时累加**，
激活状态永久保留（命令可撤销），效果同样**只在佩戴时生效**；赎罪后按表中「赎罪后」一列变化。

| 罪 | 触发条件（佩戴时累计） | 激活效果 | 赎罪后 |
| --- | --- | --- | --- |
| 傲慢 | 击杀 10 个中立 / 友善生物（**末影人列入黑名单，不计入**） | 对目标伤害 `×(1 + 目标已损失生命百分比 × 1%)`；**自身受到的所有伤害 +50%** | 移除受伤增加，保留增伤 |
| 嫉妒 | 观察到 16 格内视线前方、满足「穿有任意护甲 / 身上有任意正面效果」条件的生物 | 对穿有盔甲或持有 buff 的生物额外造成 **+50% 伤害**；**8 格内有战斗 AI 的中立生物（狼、僵尸猪灵、蜜蜂、北极熊、羊驼、铁傀儡等）被强制敌对** | 移除强制敌对，保留增伤 |
| 暴怒 | 累计击杀 100 个敌对 / 中立生物 | 攻击伤害 `×随机(0.5~1.5)`；每次攻击 **15% 几率使自己受到等量伤害** | 移除自伤，随机上限提升到 **2.0** |
| 怠惰 | 累计 3 次在**晚上 8 点前**（入睡时钟 < 20:00）睡觉 | 抗性提升 I；移动 / 挖掘 / 攻击速度各 **-20%** | 移除三项减速，抗性提升升到 **II** |
| 贪婪 | 背包内钻石 > 36 颗 | 背包内每有一颗钻石、攻击力 **+1%（上限 +64%）**；**钻石少于 36 时最终伤害降至一成**；**每次死亡随机扣 3~8 颗钻石** | 移除伤害下降与死亡扣钻石，保留钻石增伤 |
| 暴食 | 累计吃 10 次总饱和度 > 8 的食物，**或**佩戴白饭 | 击杀生物回复 2 生命与 1 饥饿/饱和度；**饥饿上限压到 18（每 tick 压制，吃/喝后不会闪回 19/20）**；**每 20 秒强制扣 1 饥饿与饱和度**；**饥饿 <10 时获得缓慢 I + 虚弱 I**；**使白饭失效** | 移除四条负面，保留击杀回复 |
| 色欲 | 累计繁殖动物 10 次；**隐藏条件**：背包里带着末地烛（静默激活） | 攻击 15% 几率脱下目标一件护甲；**自身护甲值与韧性 -30%**；**受击 15% 几率把自己的护甲脱到背包** | 移除护甲削弱与受击脱甲，保留攻击脱甲 |

细节说明：

- **提示格式**：七罪之源里每一项罪最多三行——`罪名` / `·增益`（未激活时这行是**触发条件**）/ `·减益`（已赎罪时这行是**赎罪文本**，未激活时不显示）。三态颜色：未激活灰、已激活暗红↔亮红呼吸、已赎罪**纯金色**。
- **觉醒台词**：任何一项罪觉醒时，动作栏只显示该罪的一句台词，整句用**该罪的对应色**（与七宗罪碎片名字色同一套：傲慢紫 `#A020F0`、贪婪金 `#FFD700`、色欲玫红 `#E0115F`、嫉妒绿 `#0A8A5A`、暴食橙 `#FF8C00`、暴怒橙红 `#FF4500`、怠惰灰 `#B0B0B0`）；不显示罪名。
- **色欲的隐藏触发条件（背包里有末地烛）不在游戏内文本里提示**，只在本文档里保留说明。
- 中立 / 友善 = 非 `Enemy` 的非玩家生物；敌对 = `Enemy`。
- 怠惰的「晚上 8 点前」= 入睡时刻的游戏时钟早于 20:00；原版只允许夜间或雷雨入睡，
  所以正常情况下的窗口是**天一黑就睡（19:42~20:00）**，或者熬到**午夜之后（0:00~6:00）**再睡。
- 嫉妒的「观察到」= 16 格内且在视线 30° 锥内；「带 buff」指任意正面药水效果。
- 贪婪的钻石只统计玩家自身背包（36 格 + 副手 + 盔甲槽），不含 Curios 与箱子。
- 暴食未赎罪时饥饿上限取 `min(18, 当前环境下限)`（装了 enchantment-reforged 的「大胃袋」也一样）。

`running FREEZE_DATA in COMPLETE` 与图集行（本地实测 3 次，含去数据包/去模型的诊断包）；把 Loader 与
Kilt 一起升到上表第二行后一切正常（能进存档）。升级用的三个 jar 与步骤见 `JAR\_kilt-upgrade\`。

反面案例：`Kilt 20.1.20` 配 `Fabric Loader 0.18.4` 会在资源加载结束时崩在
`transform method call failed`（本地 5 个 JVM 均复现），换 20.1.16 或把 loader 升到 0.19.5 即可。

**Kilt 侧实测还需要（Kilt 元数据里只标 optional）：**

- **Sodium + Indium**：Kilt 有一整套围绕 Sodium 渲染管线的兼容层（`kilt/mixin/compat/sodium/*`、
  `MultiPartBakedModelInject`）与 `compat/indium/BakedModelMixin`；装了 Sodium 后必须由 Indium
  提供 Fabric Rendering API 后端，否则 Forge/Porting Lib 的模型管线没有后端。
- **Architectury API**：Kilt 并没有依赖它（只在内部提供兼容层），不是硬性要求；但建议保留，
  你两个可用的实例里都有。

**Kilt 明确不兼容**：Async、Embeddium；不支持 Quilt Loader。Kilt 自述 alpha，崩溃请报 Kilt 仓库。
本模组**不新增任何依赖声明**（`mods.toml` 仍是 forge + minecraft + curios），以上只是整合包侧说明。

**「启示之光」的实现说明**：

- 数据包只保留自定义伤害类型 `summy-reliquary:revelation_light`（用于致死提示文案）、**不覆盖任何原版
  `damage_type` 标签**；圣光用的是 `summy-reliquary:holy_light`，并列入原版
  `bypasses_armor` 标签（→ 变种魔法口径）；献祭用的是 `summy-reliquary:sacrifice`（真实伤害口径）；
- 光束固定在发射点与方向上**持续 1.5 秒**，每 0.1 秒对"此刻在圆柱体内"的生物结算一次 7 点（中途进入就吃、
  离开就停；站满 1.5 秒共 15 次 = **105 点**），每次结算前都会把目标无敌帧清零；
- 「真实伤害」由代码完成：每次结算登记期望值，`LivingHurtEvent`（护甲计算之前）记录进入时黄血，
  `LivingDamageEvent` 里先替原版扣黄血、再把血量伤害设为「期望值 − 已扣黄血」，因此每一下都固定 7 点、
  **先扣黄血**、无视护甲/附魔保护/抗性；也正因为是固定值，光柱不吃「伯列恒之星 +20% 伤害」加成；
- 特效：沿柱体交替生成**白色 `END_ROD` 与金色 `WAX_ON` 粒子**（无末端冲击环），光柱本体渲染为
  **白 → 金渐变**并随持续时长淡入淡出；
- 兜底：注册表里查不到该伤害类型时自动退回 `minecraft:sonic_boom`，不会报错。

**启动卡顿排查**：若日志卡在模型报错之后、没有 `running FREEZE_DATA in COMPLETE`，先按上面的表格把
Kilt 组合升级到 0.19.5 + 20.1.20；仍卡就在卡住时抓一份线程快照（`jstack <游戏进程PID>`）发出来。

补充说明：

- **数值都走配置文件**，提示文案里出现的数字（思想发光半径、灵魂魂心与换算比例与刷新秒数、终末天启魂心、
  伯列恒之星攻速/伤害/揭示秒数、灵台套装描述）也按当前配置生成，改完配置文案会一起变。
  不纳入配置的只剩纯表现常量（粒子散布、几何宽松度、音效音高等）。
- **思想的发光半径默认 24 格**：如果你的 `config/summy_reliquary-common.toml` 是旧版本生成的、
  里面写死了 `glow_radius = 15`，请把那一行改成 `24`（或删掉该行取新默认）。
- **受伤无敌帧**分两档：**一般受伤**默认 5 tick（0.25 秒，即每秒最多 4 次有效伤害）、**帧伤 / 持续环境伤害**默认 10 tick（= 原版 0.5 秒），对所有生物生效、可配置；关掉 `enable_invulnerability_change` 或把两档都设 10 即完全回原版。
- **攻击速度上限**会把 ATTACK_SPEED 属性整体压到 4.0；剑等本身低于 4 的武器不受影响。
- **加护共 2 格**：天使线是救恩 / 圣光 / 神圣斗篷 / 圣心（四者都**需要天使标记**，任意两件可同时佩戴、第三件没位子）；
  恶魔线是**复仇之魂（邪恶 100）/ 夜之幽魂（邪恶 500）/ 玄秘魔眼（邪恶 700）/ 深渊领主（邪恶 900）**（需要恶魔标记 + 各自邪恶度已解锁，同为 2 格、任选两件）；
  七罪阶段这一栏是 **0 格**（见栏位阶段表）。
- **圣光**的判定基准是「各类倍率算完、目标减伤之前」的那次命中伤害：同一次攻击的分段（例如 ER 魔剑的追加魔法伤害）会**求和后只掷一次**，而**同源再打一次**（例如 ER 出其不意）算**两次独立攻击**、各自掷点；命中数量、伤害百分比都在 `[holy_light]` 里调。
- **神圣斗篷**的 1 秒无敌不区分伤害来源（虚空与指令也拦），期间不刷新不叠层；因为它是先取消伤害，灵台「免死」几乎不会被触发。
- **圣心 / 神性 / 契约与邪恶度的加伤**：三者是**同一个「全伤害最终倍率」乘区**（相加后再乘：圣心 +30% / 神性 +20% / 契约 +16% / 邪恶度按奇偶交替另加），且不作用于本模组的神性伤害（圣光 / 光柱 / 领域）；神性的光环与死亡拦截在 `[godhead]`，圣心属性在 `[sacred_heart]`，契约与邪恶度全部在 `[demon_pact]`。
- **恶魔契约与邪恶度**：契约的伤害/攻速/诅咒加成/生命吸取、献祭伤害、黑心心数与吸收换算、邪恶度分档与每日上限/衰减都在 `[demon_pact]` 里调；邪恶度的**获取速率目前是占位默认值**（友善 1 / 中立 0.5 / 敌对 0.1 / 监守者与凋灵 10 / 末影龙 20），等具体数值确定后改配置即可。黑心 HUD 的贴图在 `textures/gui/demon_black_heart/`，直接替换 PNG 就能换外观。
- **经文引用统一加「——」前缀**（如 `——《诗篇》32:11`），以后新增的经文行请沿用这一格式。
- **魂心（独立池）**：不混进原版吸收值，而是**自己的池子**（`soul_heart_points`），因此不会再和其它模组的护盾互相挤占。
  - 结算顺序：**原版吸收 / 护盾 → 魂心 → 黑心 → 真实血量**；原版黄心照常显示，我们的蓝心**与黑心各自独立占行**（蓝心避开盔甲那一排、黑心再在蓝心之上），所以不会覆盖黄心或盔甲图标。
  - 容量 =（灵魂 +3 / 终末天启·神性 +2 心，**相加**）× `absorption_per_soul_heart`，**不设固定总量上限**；装备时补满、每 30 秒补缺额、卸下清空。
  - **完全破碎**（池子从 >0 归零）时：击退 **7 格**内与神性光环同口径的敌人 + 给玩家 **5 秒无敌**（只触发一次）。
  - 客户端 HUD 用的是**同步过来的池子点数**（协议 `"12"`），所以蓝心会随受伤减少、随时间补满。
  - ⚠️ 旧版本把魂心算进吸收值（日志里的 `黄血=46.0（我方 6.0）` 那种口径）**已作废**；控制台日志现在改打 `魂心池=x`。

## 常见问题

- **受击看不到掉血？** ① 是否戴着「灵魂」——黄血会先被打掉，红色心不动；② 测试世界是否残留无敌/创造标记（自检脚本跑完会自动清除无敌）；③ 测试生物在简单难度伤害本来就低。
- **重登后饰品位空了 / 饰品掉回背包？** Curios 在**读档**时（`readTag → isItemValid`）会逐个调用本模组的 `canEquip` 做合法性校验，而那一刻 Forge 还没把 `summy_reliquary` 根标签写进实体，若不特判就会把 6 件门槛饰品退回背包。本模组采用「**本模组数据未就绪 → 放行**」：登录过程中不再卸装，正常游戏里门槛照旧，日志会打印 `canEquip 放行：原因=数据未就绪（读档阶段）`。历史上已经掉回背包的旧物品需要手动装回一次。
- **心之碎片的掉落怎么快速验证？** 临时把 `[revelation_light] drop_chance_percent` 改成 `100`，用启示之光柱 / 救恩领域打带「启示之光」的怪（掉落时日志会打一条 `[Summy Reliquary] 心之碎片掉落：……`），验证完记得改回 `0.5`。
- **戴着圣心却没有心之碎片？** 这是设计行为：**击杀者是玩家且戴着圣心时完全不掉**。想看掉落效果请先摘下圣心；`log_drop_checks` 打开时日志会写明 `结果=被抑制（击杀者 xxx 戴着圣心）`。
- **亚巴顿 / 深渊领主 / 硫磺火 / 神性 合不出来？** 它们**都有配方**（材料见上面「内容」表）。恶魔线全套门槛：**复仇之魂 100 / 咒印 300（3×「6」）/ 夜之幽魂 500 / 硫磺火 666 / 玄秘魔眼 700（3×3 升级表）/ 深渊领主 900 / 亚巴顿 1000**，都需要**恶魔标记**且**已解锁**；未解锁时 JEI 查不到、强合会被收走产物并把材料原样退回。除 4 件成就图标物品（按设计不需要获取）外，**所有物品都有获取途径**。
- **黑心 / 魂心怎么同时兼容 Forge 与 Kilt？** 本模组**不订阅 `LivingDamageEvent`**，走的是**命中前一次算清 + 事后对账**：估算"会打到血的部分"→ 当场扣池 → 同额临时并入原版吸收；下一次命中前 / 玩家 tick 末尾按结算后的吸收值反推"护盾扣了多少、池子扣了多少"，把多并入的退回池子并还原吸收值。因为 Kilt 对**玩家**的 `LivingDamageEvent` 注入会被跳过、`LivingHurtEvent` 又会**双发**，依赖它们就会出现"池子被扣、红血照掉"。想核对细节可打开 `[combat] log_damage_pools`（默认 true，每次命中与对账各打一条）。
- **受伤无敌帧现在是怎么算的？** 先说原版口径：判定是 `invulnerableTime > 10`、字段每 tick 减 1，所以**有效窗口 = 字段值 − 10**；原版把字段写成 20，**有效其实是 10 tick（0.5 秒）**，不是 1 秒。
  本模组沿用原版判定、**只改写窗口长度**（字段值 = 窗口 + 10），并分两档：**一般受伤 5 tick（0.25 秒）**、
  **帧伤与持续环境伤害 10 tick（0.5 秒 = 原版，站火里 / 岩浆里不会再"一帧一跳"）**。
  差值结算与"`#bypasses_cooldown` 走原始数值"都交回原版，所以 ER 的魔剑 / 出其不意追加段不会被吞。
  想完全回原版：把 `[combat] enable_invulnerability_change` 关掉，或把两档窗口都设成 10。
  排查"到底是谁在连打"看日志里的 `[Summy Reliquary] 受伤节流`（`log_iframe_throttle`，每 5 秒一条）。
- **魂心是独立池吗？** 是：魂心不混进原版吸收值（免得和其它模组的护盾互相挤占），而是独立池：**吸收/护盾 → 魂心 → 黑心 → 真血**；每 30 秒补缺额，被打空会**击退 7 格内敌人 + 给 5 秒无敌**。想关掉 HUD 用 `[spirit_altar] enable_soul_heart_hud`。
- **创世纪怎么拿？为什么我看不到它的功能？** 生存里**只有一条路**：获得**神性**或**亚巴顿**时自动各发 1 个（无配方、无其它来源；创造页仍可取）。没拿到过时，提示**只有名字 + 一行「你还不知此为何物。」**——拿到过一次（哪怕后来被重置掉）就会恢复正常提示。使用条件是**天使标记或恶魔侧任一标记**，右键弹确认框、点「是」才生效。
- **用创世纪重置之后，我算不算"回到一周目"？** 算（唯一例外见下条）。重置会清掉**除成就之外的一切**：七罪、天使标记、整条恶魔线与启示属性、五芒星那句话与累计、伯列恒星的累计与坐标、痛悔短祷的终身一次、以及身上所有本模组物品，然后重发七罪之源 + 光环。所以：天使标记要**重新做一次「七罪之源 → 美德」**才会回来；恶魔线要**重新在峡谷被邀请并签约**；星要**重新累计 600 秒**才揭示坐标；痛悔短祷也**重新可用**。成就只作记录，不再影响任何发放与门槛（五芒星、伯列恒之星都是"条件驱动"，见下）。
- **我拿到启示（终末天启）之后为什么签不了恶魔契约了？** 这是刻意设计：一旦**获取过启示**（星→天启成功，或身上带着终末天启 / 神性），**恶魔交易彻底关闭**——灵魂沙峡谷驻留不再有任何邀请台词，长按右键也没有反应，五芒星提示里那两行"交易"话语也会消失。天使线的顶点与恶魔线从此互斥。想重新开放：用**创世纪**重置（它会清掉"是否获取过启示"这个属性）。
- **重置后五芒星 / 伯列恒之星怎么没了？** 它们现在是**条件驱动发放**（与成就同一条判据）：五芒星＝**七罪全触发**、伯列恒之星＝**真三件套同时佩戴**。创世纪重置会让这两个条件都不成立，所以**不会立刻补发**；等你重新把七罪全部触发 / 重新戴齐灵台三件套，就会按原途径再发一次（**不会永久丢失**）。**唯一例外**：已完成「无罪之人」的玩家仍被锁住七罪之源（这条锁按需求不重置），因此**无法再满足七罪全触发，五芒星拿不回来**。
- **六条饰品联动怎么生效？** 必须**同时佩戴两件**：神性+圣光（圣光几率 15%→25%）、神性+神圣斗篷（无敌 1→1.5 秒）、神性+圣心（追踪半径 8→12 格）、亚巴顿+咒印（黑心碎裂 40→60）、亚巴顿+玄秘魔眼（恐惧额外"移速归零"）、亚巴顿+深渊领主（狱火满级时把目标抗性等级减半并持续覆盖）。前三条与咒印那条的**提示里显示的数值会跟着变**；六条数值都在配置里（见上面 `[holy_light]` / `[holy_mantle]` / `[sacred_heart]` / `[demon_pact]` / `[occult_eye]` / `[abyss_lord]`）。
- **魂心多久回满？** 由 `[spirit_altar] soul_refresh_seconds`（默认 30 秒）控制：递减在**每秒分支**执行，**打空（完全破碎）后要重新等满一轮**。**黑心同步对齐**：刚戴上撒旦圣经立刻补满、碎裂重置计时、登录 / 换维度 / 复活时池子空了就补满；摘下撒旦圣经**不会清空**黑心池。
- **复仇之魂 / 咒印怎么拿、怎么穿？** 两件都是**恶魔线**饰品：需要**恶魔标记**并且邪恶度达到解锁门槛（100 / 300）。复仇之魂进**加护**栏、咒印进**灵台**栏；咒印可以用 3×「6」无序合成（签约没收灵台部件时也会按数量补偿）。戴咒印时灵台只需要 1 格，且它会**继承天使线灵台套装的全套属性**（含 20% 免死），代价是灵魂的魂心变黑心、邪恶度不再衰减、碎裂伤害升到 40。
- **栏位怎么变少了？** 栏位按阶段动态：**七罪阶段**灵台 / 启示之座 / 加护都是 0 格；**天使线**（有天使标记）3 / 1 / 2；**恶魔线**（有恶魔标记）1 / 1 / 2。缩格前会把格内物品退回背包（满了掉脚下），不会吞装备。
- **「6」除了签约补偿还能怎么拿？** 佩戴契约且**已解锁咒印**时，击杀**末影龙 / 凋灵 / 监守者**各掉 1 个，**各只掉一次**；**忏悔会重置**这三条记录，所以下一轮还能再各拿一次。
- **仪式法袍怎么穿不上？** 它的门槛是**恶魔线**而不是天使线：必须**签过约（或当前就是恶魔）**才能佩戴与查看功能；没签过约时提示只有名字 + 一行「你尚未与它达成交易」。它进的是 **Curios 自带的「背饰」栏**。
- **撒旦圣经怎么拿？** 不是刷的：**签过约**之后把**七罪全部重新激活**（签约时会把你已赎罪/已激活的状态重置成"全部未激活"，需要重新触发各罪的觉醒条件；已经攒够的击杀数等进度不会清零，所以重激活很快），魂印栏里的七罪之源就会**自动转化**成撒旦圣经。
- **忏悔之后我的七罪进度呢？** 签约那一瞬会被存成**快照**，忏悔（痛悔短祷换回天使标记）时**原样恢复**：带着美德签约 → 忏悔拿回美德；3 罪已赎 + 4 罪激活 → 忏悔后仍是 3+4。
- **黑心被打空了会怎样？** 池子从有到零的那一下会**炸一次**：18 格内与神性光环同口径的敌人吃 **24 点伤害**（无视护甲、保护附魔与抗性照常生效）；只炸一次，之后要等撒旦圣经每 30 秒补满才会再炸。
- **恶魔交易怎么做？** 先拿到五芒星并等那句 300 秒的话出现，再去**灵魂沙峡谷**站 5 秒听邀请，然后**手持五芒星长按右键 5 秒**签约（蓄力时视野会收缩、手中贴图会拉长，没有文字进度）。已经拥有终末天启（或已完成「启示」进度）的玩家第一次不会被邀请。
- **想再签一次（解除恶魔标记）？** 用一次**痛悔短祷**（主世界 + 出生点/重生点 8 格内 + 露天）成功使用 → 恶魔标记换回**天使标记**（名字回到金色，五芒星提示会多出「我们的约定依然作数 / 我还在那个地方等你」）→ 再回灵魂沙峡谷**长按五芒星 5 秒**即可**第二次签约**（这次没有任何对话，台词是「欢迎回来，七罪之子 / 让我们重新开始吧」）。痛悔短祷限用一次，所以最多签两次。
- **恶魔台词太慢/太快？** 改 `[demon_deal] line_delay_ticks`（默认 40 = 2 秒/行）。旧配置文件里若还写着 `20`，需要手动改。
- **签了契约之后我的圣光/救恩/斗篷/灵台三件套不见了？** 这是设计：签约＝与天国决裂，这 6 件会被**没收**（圣心不在清单内）。灵台部件每件补 1 个「6」，三件全被没收则改补 1 个咒印；3×「6」也可以无序合成咒印（需邪恶度 ≥300 解锁）。
- **用创世纪能清掉恶魔线吗？** 能。创世纪是「**除成就外全清**」，**整条恶魔线会一起被清掉**：恶魔标记 / 曾签约 / 受邀与离场记录、邪恶度与解锁位图、`hell_locked`（666 锁定）、契约与「恶魔契约」栏位、献祭与「6」掉落记录、黑心池；同时清七罪三态与计数、天使标记、启示属性、五芒星那句话与累计、伯列恒累计与坐标、痛悔短祷的终身一次，并删掉背包与饰品栏里本模组的全部物品，最后重发光环 + 七罪之源。**只保留**成就、无罪之人的锁（`sin_renounced`）与迁移标记。想**只清恶魔线、不动物品与进度**，用 OP 指令 `/summyreliquary genesis reset <玩家>`（重置一次性标记 + 清恶魔交易五个键 + 契约 / 邪恶度 / 解锁 / 黑心，并收回「恶魔契约」栏位）。
- **黑心怎么来、怎么没？** 完成**首份契约的献祭**（佩戴契约 + 击杀村民）时 +2 黑心（4 点）；它是**独立池**，
  只在**佩戴契约**时生效，扣伤顺序是「ER 护盾 → 魂心黄血 → **黑心** → 红血」。**容量＝各来源相加**：
  契约 2 心 + 仪式法袍 2 心 + 撒旦圣经 1 心 + 咒印 3 心 = **8 颗 = 16 点**（四个数值都在 `[demon_pact]` 里可调），
  **不设固定总量上限**；卸下某个来源后，超出当前容量的部分会被夹回。
  回复手段目前只有**撒旦圣经**的每 30 秒补满（摘下它不会清空池子）。
- **魂心（黄血）上面的蓝色心是什么？** **魂心 HUD**：把本模组魂心那一份（灵魂 +3 / 天启·神性 +2 × 每点吸收）用蓝心覆盖在原版黄心的位置，
  **不隐藏也不接管**原版黄心（吸收值是共用池，可能还包含其它模组的护盾）；不想看可以关掉 `[spirit_altar] enable_soul_heart_hud`。
- **邪恶度怎么涨、有什么用？** 佩戴契约时按生物档位积攒（友善 +1 每游戏日最多 20 / 中立 +0.5 / 敌对 +0.1 /
  监守者与凋灵 +10 / 末影龙 +20），每游戏日总量最多 +100、自然 −5（6:00 刷新），上限 1000；**佩戴仪式法袍把
  每日衰减降到 −3，佩戴咒印则完全不衰减；邪恶度满 1000 后会进入"锁死"状态 —— 既不再增长也不再衰减**
  （此时法袍 / 咒印的衰减修正都不参与）。每 1 点**奇偶交替**给攻击或攻速 +0.1%（1000 点各 +50%），这些加成
  只在**佩戴契约**时生效。达到 100/300/500/666/700/900/1000 会发言并**解锁对应配方**
  （未解锁时 JEI 查不到、强行合成会被拦）；**666 之后永久无法回到天使线**（痛悔短祷会被拒绝且不消耗）。
- **yes_steve_model（YSM）的模型设置老是重置？** 与本模组无关：日志里是 YSM 自己把 `yes_steve_model-client.toml` 判为不合法后重写（`is not correct. Correcting`）。本模组不碰 YSM 的任何数据。
- **装上/摘下提上限的饰品后血条没变化？** 现在属性变化会立刻生效并把当前血量夹回上限；若仍未生效，把 `logs/latest.log` 发我。
- **免死会不会挡住 `/kill` 或虚空？** 会。免死不区分伤害来源，虚空、指令这类伤害同样有几率被拦下（与 enchantment-reforged 的「灵动步伐」口径一致）。触发后的 2 秒无敌期间，所有伤害都被取消。

## 开发

- 构建：`gradlew build`（需要 Java 17，见 `gradle.properties` 的 `org.gradle.java.home`），
